
# 🏭 Manufacturing Downtime & Production Analytics

> **Data Analytics | SQL | Power BI | Business Intelligence**

An end-to-end data analytics project focused on analyzing **manufacturing downtime, machine performance, production efficiency, and operational losses**.

The project uses **SQL for data analysis** and **Power BI for interactive dashboarding**, transforming raw manufacturing data into meaningful business insights for better operational decision-making.

---

## 📊 Project Overview

Manufacturing downtime can directly impact production efficiency, machine utilization, and overall operational performance.

This project analyzes manufacturing data to answer important business questions:

- Which machines experience the highest downtime?
- What are the major causes of downtime?
- Which machines contribute most to production losses?
- How does downtime vary across different periods?
- What is the relationship between production and downtime?
- Which areas should management prioritize for improvement?

---

## 🎯 Business Objectives

- Analyze overall manufacturing performance
- Identify major downtime contributors
- Compare machine-level performance
- Understand downtime patterns and causes
- Analyze production efficiency
- Identify operational problem areas
- Provide actionable insights for management

## 📌 Business Recommendations

Based on the analysis, organizations can consider:

1. **Prioritizing high-downtime machines** for maintenance.
2. **Investigating recurring downtime causes** to identify root problems.
3. **Using preventive maintenance** to reduce unexpected machine failures.
4. **Monitoring machine-level KPIs** regularly.
5. **Tracking downtime trends** to identify recurring operational issues.
6. **Using dashboard insights** to support data-driven production decisions.
